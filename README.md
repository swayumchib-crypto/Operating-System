# 🖥️ Operating Systems Lab Experiments

This repository contains a collection of **Operating Systems (OS) Lab experiments** implemented using Linux commands, Shell Scripting, and C programming.

The experiments cover fundamental Operating System concepts, including process management, memory allocation, string manipulation, system calls, and system resource monitoring.

## 📂 Repository Structure

### 1. Shell Scripting & Linux Basics

| Experiment | Description |
|---|---|
| `exp1` | Demonstrates basic Linux commands and their syntax. |
| `exp2` | Covers date commands and text processing using `sed`. |
| `exp3a.sh` | Introduction to basic shell scripting and logical operations. |
| `exp3b.sh` | Extended shell scripting concepts. |
| `exp4a.sh` | Shell scripting operations and command-line concepts. |
| `exp4b.sh` | Demonstrates additional shell scripting techniques. |
| `exp4c.sh` | Covers various shell scripting operations. |

### 2. C Programming & String Handling

| Experiment | Description |
|---|---|
| `exp5.c` | Implements string length calculation and substring extraction. |
| `exp5.sh` | Shell script used to execute the string manipulation program. |
| `exp10.c` | Demonstrates the Process ID (PID) and memory address of a variable. |

### 3. Memory & Process Management

| Experiment | Description |
|---|---|
| `exp6.c` | Demonstrates dynamic memory allocation using C. |
| `exp7a.c` | Implements an infinite counter process that can run in the background. |
| `exp7b.c` | Demonstrates an I/O-bound process through continuous file writing. |
| `exp9.c` | Demonstrates process creation and synchronization using `fork()` and `wait()`. |

### 4. System Monitoring & Analysis

| Experiment | Description |
|---|---|
| `exp8.sh` | Demonstrates process memory mapping using the `pmap` command. |

## 🛠️ Prerequisites

To execute these experiments, you need:

- **Operating System:** Ubuntu, Debian, or WSL (Windows Subsystem for Linux).
- **Compiler:** GCC (GNU Compiler Collection).
- **Shell:** Bash.
- **Utilities:** Standard Linux commands and tools.


## 🎯 Learning Objectives

Through these experiments, the repository aims to provide practical understanding of:

- Basic Linux commands and shell operations.
- Shell scripting and automation.
- C programming in a Linux environment.
- String manipulation and memory addresses.
- Dynamic memory allocation.
- Process creation and management.
- Parent-child process synchronization.
- CPU-bound and I/O-bound processes.
- Memory mapping and system monitoring.
